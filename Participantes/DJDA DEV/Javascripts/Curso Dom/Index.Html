Hola DJDA

Bienvenido al curso de DOM, aquí aprenderás a manipular el Document Object Model (DOM) utilizando JavaScript. El DOM es una representación estructurada de un documento HTML o XML, que permite a los desarrolladores interactuar con los elementos de la página web de manera dinámica. A lo largo del curso, exploraremos cómo seleccionar elementos, modificar su contenido, agregar eventos y mucho más para crear experiencias web interactivas y atractivas.s
