# Bienvenido a "Course F and D"

¡Hola! Acabas de ingresar a un buen repositorio... ¡Enhorabuena, mano!

Esta idea de colaborar entre personas consiste en recopilar información relacionada con la programación, utilizando recursos de aprendizaje propios y documentación de diferentes fuentes. Obviamente, no toda la información es mia y ni mucho menos inventada.Pero tienes que saber que el objetivo principal es construir una biblioteca de conocimientos que sirva como respaldo de la información que adquiramos y que seguirémos adquiriendo a lo largo de nuestra formación.

Esta documentación no solamente me ayudará a mí, sino también a todas aquellas personas que puedan y quieran aprovechar estos recursos.

Recuerda: todo es difícil, pero no imposible. ¡Échale ganas!

## Participaciones
Hola de nuevo !, Queria proponerte algo... , y eso es que:

 - Comparte tus conocimientos y recursos de programación.
 - Puedes dejar tu feedback y sugerencias para mejorar el proyecto
 - puedes crear tu carpeta con tus recursos 

Esto lo puedes hacer con tu nombre de usuario o como gustes, en la carpeta que te corresponda e igual que por medio de pullRequest se iran revisando y anexando al repositorio

#### Pasos para lograrlo
1- Clonar el repositorio
```
git clone URL_DEL_REPOSITORIO
```
2- Crea tu propia Rama
```
git checkout -b feature/<Nombre>File
```

Ejemplos:
```
 git checkout -b feature/DJFile
 git checkout -b feature/<TuUsuario>File
 git checkout -b feature/MariaFile
```
3- Sube tu Rama
```
git push -u origin feature/<Nombre>File
```
Todo se hace con el objetivo de que cada colaborador utilice su propio identificador para evitar confusiones.

### Crea tu Pull Request

* Ingresa al repositorio en GitHub.
* Selecciona la opción Compare & pull request.
* Verifica que la rama base sea main.
* Selecciona tu rama como rama de comparación.
* Describe brevemente las aportaciones realizadas.
* Envía tu Pull Request.
